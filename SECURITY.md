# Security policy

## Segnalazione

Non pubblicare dettagli di vulnerabilità non corrette nelle issue. Invia una segnalazione privata al maintainer tramite la funzione **Report a vulnerability** nella scheda Security del repository GitHub. Includi i passaggi per riprodurre il problema e l'impatto osservato; non allegare dati personali o segreti.

## Ambito

Il progetto è una pagina statica senza backend e senza dipendenze runtime. Le modifiche di sicurezza vengono validate con i test e con CodeQL.
